# Прийом заявок у Telegram

Форма на сайті має віддавати заявки в Telegram. Нижче — два способи.

> **Токен нікому не показуйте.** Ви вписуєте його самі: у налаштуваннях
> Cloudflare (варіант А) або у файл на своєму компʼютері (варіант Б).
> Не надсилайте його в чат, у листі й не комітьте в репозиторій.

---

## Варіант А — через Cloudflare Worker (рекомендую)

Токен лежить у Cloudflare, а не в коді сайту. Безкоштовно, ліміт —
100 000 запитів на добу, для форми це з великим запасом.

### 1. Створіть бота

1. Напишіть [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Придумайте імʼя і нік боту → отримаєте **токен** виду
   `7712345678:AAG...`. Скопіюйте, нікому не пересилайте.

### 2. Номер чату вже вписаний

Група для заявок — `-1004475490563`. Він уже стоїть у `worker.js`,
окремо додавати не треба. Якщо колись зміните групу — виправте
`DEFAULT_CHAT_ID` угорі файлу.

### 3. Створіть Worker

1. [dash.cloudflare.com](https://dash.cloudflare.com) → зареєструйтесь.
2. **Compute (Workers)** → **Create** → **Start from Hello World** →
   назвіть `medorion-form` → **Deploy**.
3. **Edit code** → зітріть усе, що там є, і вставте вміст файлу
   [`worker.js`](worker.js) → **Deploy**.

### 4. Додайте токен — одну змінну

**Settings** → **Variables and Secrets** → **Add**:

| Імʼя | Тип | Значення |
|---|---|---|
| `BOT_TOKEN` | Secret | токен від @BotFather |

Збережіть і задеплойте ще раз. Більше нічого додавати не треба.

### 5. Впишіть адресу Worker'а в сайт

Cloudflare покаже адресу виду
`https://medorion-form.ваш-акаунт.workers.dev`.

Відкрийте `assets/js/main.js`, угорі:

```js
var TG_ENDPOINT = 'https://medorion-form.ваш-акаунт.workers.dev';
```

Збережіть, закомітьте, залийте на GitHub. Готово.

### 6. Перевірте

Заповніть форму на сайті. Заявка має прийти в чат за секунду.
Якщо ні — Cloudflare → ваш Worker → **Logs**: там видно причину.

## Варіант Б — швидкий, без Worker'а

Якщо треба, щоб працювало просто зараз. У `assets/js/main.js`:

```js
var TG_BOT_TOKEN = '7712345678:AAG...';
var TG_CHAT_ID   = '-1002345678901';
```

Працює одразу, **але**: репозиторій сайту публічний, і токен побачить
кожен, хто відкриє сторінку. З ним стороння людина зможе слати
повідомлення у ваш чат від імені бота та міняти налаштування бота.
Читати ваші заявки вона не зможе — бот їх не отримує, а надсилає.

Якщо токен усе ж засвітився: @BotFather → `/revoke` → отримаєте новий,
старий одразу перестане працювати.

## Захист від спаму

У формі є приховане поле `company`. Людина його не бачить і не
заповнює, а автоматичні спам-боти заповнюють усі поля підряд. Якщо
воно не порожнє, Worker мовчки відкидає заявку — відправник бачить
звичайне «дякуємо» і не розуміє, що спрацював фільтр.

Це відсіює масовий спам. Якщо колись почнуть слати вручну — додамо
обмеження за IP через Cloudflare KV.
