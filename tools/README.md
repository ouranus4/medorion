# Як зроблено білі силуети партнерів

`assets/img/partners/*.webp` — оригінали, як їх дали партнери: різні
за кольором, частина намальована темним по білому.

`assets/img/partners/w/*.webp` — те саме, зведене до білого силуету на
прозорому тлі. Стіна партнерів на сайті лежить просто на чорному, без
плашок, тож темний логотип там би просто зник.

Порядок запуску (потрібні Pillow і numpy):

```
python tools/whiten-logos.py      # силует: витягує форму й фарбує в біле
python tools/lift-logos-gamma.py  # загальна гама, щоб тонкі лінії не сіріли
python tools/lift-logos-faint.py  # доводить окремі надто бліді файли
```

Головна складність — визначити, що в файлі логотип, а що підкладка.
Скрипт пробує обидві полярності (темне по світлому і навпаки) і бере
ту, після якої лишаються штрихи, а не суцільна пляма. Кілька файлів,
де ця перевірка помиляється, перелічені вгорі `whiten-logos.py` у
`FORCE_ALPHA` і `FORCE_MODE`.

Після перегенерації розміри картинок міняються (їх обрізає по вмісту) —
атрибути `width`/`height` у `index.html` треба оновити.
