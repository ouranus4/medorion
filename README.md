# MedOrion Awards 2026 — лендинг

Статичний сайт: чистий HTML/CSS/JS, без збірки та залежностей.
Достатньо залити папку на будь-який хостинг (Netlify, Vercel, звичайний shared-хостинг).

```
index.html
assets/
  css/main.css
  js/main.js
  img/  logo.png · statue.png · statue-red.png · favicon.png
        channels/   14 логотипів каналів
        gallery/    26 фото з церемонії
        laureates/  (порожня — під портрети лауреатів)
```

## Що треба заповнити

### 1. Telegram-бот для заявок

Повна інструкція: **[telegram-worker/README.md](telegram-worker/README.md)**.

Коротко: створюєте бота в `@BotFather`, піднімаєте безкоштовний
Cloudflare Worker з файлу `telegram-worker/worker.js`, вписуєте туди токен
і `chat_id`, а в `assets/js/main.js` — тільки адресу Worker'а:

```js
var TG_ENDPOINT = 'https://medorion-form.ваш-акаунт.workers.dev';
```

Так токен лишається у Cloudflare і не потрапляє в публічний репозиторій.

Є й швидкий варіант — вписати `TG_BOT_TOKEN` і `TG_CHAT_ID` просто в
`main.js`. Працює одразу, але токен побачить кожен відвідувач сторінки.

Поки нічого не заповнено, форма не мовчить: вона показує «Напишіть напряму:
t.me/marina_philipenko», тож жоден лід не губиться.

У формі є приховане поле-пастка `company` проти спам-ботів — не видаляйте його.

### 2. Посилання на телесюжет СТБ

У `assets/js/main.js`:

```js
var STB_VIDEO_URL = '';   // порожньо -> кнопка «Дивитися сюжет» прихована
```

### 3. Фото для блоку «Кому і навіщо»

Чотири круглі портрети в картках сегментації. Покладіть у `assets/img/segments/`:

| Файл | Кому |
|---|---|
| `cosmetology.jpg` | лікарка-косметологиня |
| `surgery.jpg` | пластичний хірург |
| `clinic.jpg` | власник(-иця) клініки |
| `brands.jpg` | бренди та дистрибуція |

Квадратні, від 400×400 — вони обрізаються в коло. Поки файлу немає,
показується тонка лінійна іконка, і в консолі видно `404` на цей шлях —
це штатна перевірка наявності фото, а не помилка.

### 4. Партнери сезону

Логотипи лежать у `assets/img/partners/` — 62 файли `p01.webp` … `p64.webp`,
обрізані по краю малюнка й стиснені до ширини 440.

Кожен лежить на власній плашці. Білій — за замовчуванням; темній
(`class="ptile ptile-dark"`) — тільки ті, що намальовані світлим по
прозорому фону, інакше вони зникають на білому. Щоб додати партнера:
покладіть файл у папку, скопіюйте будь-який `<li class="ptile">` у секції
`#partners` і підставте імʼя файлу та назву бренду в `alt`/`title`.

Вихідники (PDF, AI, SVG) лишились у `photos/партнери 2025/`.

### 5. Експертна рада

Портрети семи членів Ради лежать у `assets/img/board/` — цілі промо-картки
з Instagram, стиснені до ширини 760, точно як портрети лауреатів. Посилання на їхні пости — у
`assets/js/main.js`, у списку `LAUREATE_INSTAGRAM` (нижній блок «Експертна
рада»). Щоб додати людину: покладіть квадратне фото в цю папку, скопіюйте
блок `<article class="lau">` у секції `#board` і додайте рядок у список
посилань — ключ має збігатися з `data-key`.

Аватари в кружечках під кнопкою на першому екрані — `assets/img/faces/`,
160×160, нарізані з карток лауреатів. Там лежать усі девʼять; на сторінці
показані пʼять, решта — про запас, міняються одним рядком у розмітці.

### 5. Портрети лауреатів

Покладіть файли в `assets/img/laureates/` з такими іменами:

| Файл | Кому |
|---|---|
| `marina-kinakh.jpg` | Марина Кінах |
| `anna-holovko.jpg` | Анна Головко |
| `grand-cosmetic.jpg` | Grand Cosmetic |
| `olha-samokhvalova.jpg` | Ольга Самохвалова |

Формат: вертикальні 3:4, мінімум 600×800. Скрипт сам підхопить файл і замінить
монограму на фото — правити код не треба. Поки файлу немає, показується
типографічна монограма (МК / АГ / GC / ОС).

## Дизайн-система — Apple Dark Aesthetic

| | |
|---|---|
| Тло | `#0A0A0C`, hero — чистий `#000000`, без світлих плям |
| Текст | білий `#FFFFFF`, підзаголовки `#A1A1A6`, підписи `#6E6E73` |
| Ключові слова | градієнт у холодний графіт `#86868B` (клас `.mute`) |
| Акцент | рубіновий `#E50914` / `#8B0000` — тільки тонкі лінії, ховер-свічення, головні кнопки |
| Картки | матове скло: `rgba(255,255,255,.03)`, бордер `rgba(255,255,255,.08)`, радіус 28px, `backdrop-filter: blur(20px)` |
| Шрифт | Inter / SF Pro Display 400–700, трекінг `-0.03em` |

Розділи розділені волосяними лініями, а не кольоровими блоками. При наведенні
на картку під курсором розквітає м'яке рубінове світло (координати передає JS
у змінні `--mx` / `--my`).

## Структура сторінки

Hero · Кому і навіщо · Звіт за минулий сезон · Лауреати · Медійна артилерія ·
Головний вечір · Напрями відбору · Екосистема Business GRAVITY · PR-супровід 365 ·
Форма реєстрації · Футер.

**Hero** — чиста типографіка в стилі Apple Keynote, усе по центру: капсула з датою,
срібний логотип, монументальний заголовок, рубінова кнопка з капсулою квот, лічильник.
Жодних об'єктів, пілюль та іконок усередині тексту.

**Анімований градієнт у hero.** `<canvas id="heroGradient">` малює WebGL-шейдером
шовкові рубінові смуги світла, що повільно обертаються навколо точки за правим
верхнім кутом. Це чистий WebGL без бібліотек: вершинний шейдер малює один трикутник
на весь екран, фрагментний рахує колір із кута й радіуса. Параметри всередині
`assets/js/main.js`, у блоці `heroGradient`:

- `t * 0.085` у `float t` — швидкість обертання;
- три `sin(a * N …)` — кількість і форма смуг;
- `vec3(0.90, 0.05, 0.09)` та сусідні — колірна шкала від чорного через винний до рубіну;
- `smoothstep(1.45, 0.02, r)` — як далеко світло дістає від свого джерела.

Поверх шейдера лежить `.hero-scrim` — затемнення, що тримає заголовок читабельним.
Якщо WebGL недоступний, шейдер тихо не запускається і hero лишається чорним.
При `prefers-reduced-motion: reduce` малюється один статичний кадр без анімації.
Щільність пікселів обмежена 1.5×, бо шейдер на весь екран.

**Star button.** Усі кнопки — темні пілюлі з трьома шарами:

1. **Кільце зі світловою дугою.** `.btn::before` — конічний градієнт, кут якого
   анімується через зареєстровану властивість `@property --star-a` (цикл 4,4 с).
   Маска `mask-composite: exclude` лишає видимим тільки контур завтовшки 1px, тож
   дуга світла їде по периметру. Загорнуто в `@supports` — де маски немає,
   лишається звичайний тонкий бордер.
2. **Ореол.** `.btn::after` — той самий градієнт із `blur(7px)`, що виходить за межі
   кнопки. Саме тому на `.btn` **немає** `overflow:hidden` — інакше ореол би зрізало;
   канвас натомість скругляє себе сам через `border-radius:inherit`.
3. **Зоряне поле.** `<canvas class="btn-sparks">` із частками, що дрейфують і
   мерехтять. `z-index:-1` при `isolation:isolate` кладе зорі поверх заливки, але під
   текст; `pointer-events:none` не заважає клікам. Один спільний цикл
   `requestAnimationFrame` на всі кнопки, малюються лише ті, що на екрані.

Колір світла задається змінною `--star-light` на кнопці: `.btn-ruby` — фірмовий
рубін, `.btn-white` і `.btn-ghost` — біле. При `prefers-reduced-motion: reduce`
обертання зупиняється, зорі не вмикаються, кільце лишається статичним.

**Анімація логотипа.** Логотип повільно ширяє (`logoFloat`) і по ньому раз на 6 секунд
проходить металевий відблиск (`sheen`). Відблиск — це градієнт, обмежений маскою
`mask-image: url(logo.png)`, тому світло йде строго по срібних літерах і ніколи не
виходить за них. Обидві анімації вимикаються при `prefers-reduced-motion: reduce`.

## Локальний перегляд

```bash
python -m http.server 8899
```

Далі відкрити `http://localhost:8899`. Просто відкрити `index.html` подвійним
кліком теж можна, але через `file://` частина браузерів блокує підвантаження фото.

## Технічні нотатки

- **Фото церемонії** дістані з попереднього лендингу, де вони були вшиті в HTML
  вже стисненими (211–340px по ширині). У мозаїці вони виглядають нормально, але
  якщо є оригінали — покладіть їх у `assets/img/gallery/` з тими самими іменами,
  сторінка стане помітно чистішою на Retina-екранах.
- **Статуетка** зі сторінки прибрана. Файли лишились у `assets/img/`:
  `statue-ruby.png` (срібло + рубіновий диск), `statue-red.png` (помаранчевий),
  `statue.png` (оригінал із синім диском). `statue-ruby.png` досі вказаний як
  `og:image` — це картинка для прев'ю в соцмережах, на самій сторінці її немає.
  Якщо потрібно інше прев'ю, замініть `og:image` у `<head>`.
- **Логотипи каналів** на чорному тлі: за замовчуванням темні марки інвертуються в
  білий. Логотипи, де літера вибита всередині суцільної форми (СТБ, Новий канал,
  Прямий, Радіо П'ятниця), позначені класом `keep` — їх не можна інвертувати,
  інакше літера зникає. Знімок `Ми-Україна+` видалено — це був непрозорий блок.
- У консолі браузера видно 4 запити `404` на портрети лауреатів — це штатний
  механізм підстановки фото, він зникне, щойно покладете файли.
- **Адаптив**: перевірено на 375 / 768 / 1440 — горизонтального скролу немає,
  усі поля форми 16px (iOS не зумить), на телефоні картки лауреатів і логотипи
  гортаються вбік, унизу липка кнопка заявки.
